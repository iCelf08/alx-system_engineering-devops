Software System Infrastructure Overview
Background
As a Full-Stack Software Engineer, you're expected to understand the entire software stack, including its infrastructure components. A comprehensive understanding involves knowing how different layers and services interact within the system. This project will help you explore and articulate the infrastructure aspects of a software system, including networking, servers, and security.

Objective
The goal of this project is to provide a detailed overview of how a software system operates from an infrastructure perspective. Key areas of focus will include:

DNS Requests
TCP/IP Protocol
Firewalls
HTTPS/SSL Encryption
Load Balancers
Web Servers
Application Servers
Databases
Deliverables
Blog Post: Write a blog post detailing your understanding of the software system infrastructure. You can publish this on LinkedIn, Medium, or another platform of your choice.
README.md File: Include a README.md file at the root of your project folder. This file should provide an overview of your blog post and instructions for accessing it.
Review Process
Before the project deadline, ensure your blog post is reviewed by a peer. If no peer reviewers are available, you should request a review from a Teaching Assistant (TA) or staff member.
